# Calibration workbench

Use the actual wood photograph, reference photograph and Blender preview as the visual focus. No decorative imagery or external fonts.

Palette: worktable #e4e8eb, paper #ffffff, graphite #282c30, ink #151719, blueprint blue #376782, maple #baab90. Avenir Next with Trebuchet MS fallback, consistent sentence-case labels.

Layout: narrow tool inspector on the left; the source photograph/crop or finish reference in the middle; the latest rendered guitar on the right. The toolbar selects photograph, finish and camera. On smaller screens the panels stack. Inputs remain left aligned and precise values are visible beside sliders.

Distinctive element: dragging measured crop corners directly on the actual source photograph. Everything else supports inspection: quiet surfaces, ordinary buttons, a stable render viewport and clear job status.

Review: avoid ornamental cards, all-cap labels and animated decoration. The real maple and guitar provide the visual identity. Separate stain, burst and surface settings because each corresponds to an independent finishing decision.
